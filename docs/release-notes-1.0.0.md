# mac-videos 1.0.0

Record a project walkthrough on your Mac: choose a display and microphone, add a draggable camera bubble, and save an H.264 MP4 locally. Stop from any app with Shift–Command–S. The recordings list shows thumbnails, duration and file size.

You can optionally upload an unlisted copy to YouTube after confirming each upload. Your local recording stays on your Mac. Each user configures their own Google project and Desktop OAuth client; no shared client ID is included. Anyone with an unlisted link can watch.

Requires macOS 27 or later. Download the universal ZIP, unzip it and move mac-videos.app into Applications. See the [user guide](https://github.com/GolferGeek/mac-videos/blob/main/docs/user-guide.md) for the three recording permissions and optional YouTube setup.

Upgrading from a development build: paste your existing Google client configuration once in Settings and sign in again. Older Keychain items are untouched. Screen Recording permission may need to be enabled again after the signing change.
